# Tag v1.0.0 for open-core; proven production claims need unaided pilots

Status: accepted

The public artifact tag is `v1.0.0` for the quiet open-core self-host kernel after the local release gate. That tag means installable, API-frozen, lab-verified software — not “battle-tested at customers.” Marketing proof language requires the Proven Claim Gate: at least Pilot Done (Unaided) for Pilot #1; repeatability claims require clone Pilot #2. Keeping the product at v0.x until two pilots, or claiming full production proof at tag time, were rejected as either under-selling a frozen `/v1` kernel or over-claiming lab evidence.
