# Open-core free surface includes operator UI and optional Slack

Status: accepted

Self-host ActantOS is free for the enforcement kernel, web approval, basic dashboard, optional Slack connector, policy templates, and local audit export. Paid surface is hosted control plane, enterprise identity/isolation, managed compliance export, and white-glove support — not core approval or basic ops UI. Alternatives (locking UX behind paywall, or all self-host free with only hosting paid) either break coding-agent pilots or under-package enterprise value. This cut keeps Design Partner Pilots honest on the free path while preserving a clear commercial upsell.
