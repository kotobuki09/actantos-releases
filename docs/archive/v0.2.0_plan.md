# v0.2.0 — Demo Hardening MVP

> **Status:** ✅ **COMPLETE** (historical). Engineering delivered as part of the path to local v1. Do not open new tickets here.
>
> **Prerequisites:** Read `00_global_rules_and_teams.md` first for team lanes, global rules, and ticket format.
>
> **Canonical next work:** `v1.0.0_plan.md` (Quiet Open-Core Release) then `design_partner_window_plan.md`. Strategy: `CONTEXT.md`, `docs/adr/`.

## Goal
Make the current kernel demo-safe and reviewer-safe: Slack approvals, redaction everywhere, guarded tool expansion, minimal operator console, and Cedar provider stabilization.

## Entry criteria
```text
- Week 1 demo passes against local daemon on port 3100
- Existing manual approval API still works
- Existing guarded_read and guarded_bash tests pass
- Existing MCP baseline remains green
- No open P0 security bug in current kernel
```

## Non-goals
```text
- OIDC / SSO authentication
- Credential broker
- SIEM / webhook exports
- Full policy marketplace
- gVisor / Firecracker sandboxing
- Multi-tenant SaaS
- Full product dashboard (only minimal operator console)
```

### v0.2-C: Guarded Pi Tool Expansion
**Owner:** A3 Pi Adapter
**Support:** A1 Core API/DB, A5 Security/QA

**Tools to implement:**
```text
guarded_write
guarded_edit
guarded_ls
guarded_grep
guarded_find
guarded_http
guarded_github
```

**Shared rules:**
```text
- Canonicalize before decision
- Re-verify canonical target before execution
- Never execute raw user path
- Deny canonicalization failure
- credential_access=true always denies
- Missing daemon response means fail closed
- Unsupported schema version means fail closed
```

**Tasks:**
```text
v020-PI-001 Extract shared path canonicalization helper
- root
- cwd
- symlink resolution
- separator-safe prefix check
- Windows/Unix path behavior tests if relevant

v020-PI-002 Implement guarded_write
- mutation=true
- verb=write
- credential path deny
- audit diff metadata, not full sensitive content

v020-PI-003 Implement guarded_edit
- mutation=true
- verb=write
- capture redacted diff preview
- deny edit on credential paths

v020-PI-004 Implement guarded_ls
- verb=list
- mutation=false
- safe workspace only

v020-PI-005 Implement guarded_grep
- verb=read/list
- mutation=false
- redact matched preview
- deny credential paths unless policy explicitly allows safe metadata only

v020-PI-006 Implement guarded_find
- verb=list
- mutation=false
- deny traversal outside workspace

v020-PI-007 Implement guarded_http
- verb=network
- network=true
- SSRF precheck
- network_mode only none|egress_proxy
- network_allowlist is data, not enum

v020-PI-008 Implement guarded_github
- classify gh commands/actions
- git push / release / secret / deploy -> approval_required
- auth/token operations -> deny unless explicit safe demo mode
```

**Acceptance tests:**
```text
- write safe file -> allow
- write .env -> deny
- edit README.md -> allow or approval depending policy
- edit .ssh/config -> deny
- ls workspace -> allow
- ls / -> deny
- grep README.md -> allow
- grep .env -> deny or redacted deny path
- find workspace -> allow
- find ../../ -> deny
- http localhost -> deny
- http 169.254.169.254 -> deny
- github push dry-run -> approval_required
```

**Done when:**
```text
- All guarded tools fail closed on daemon error
- All guarded tools use canonical resource in decision and execution
- All guarded tools create correct audit events
```
