## Goal

Publish a **Quiet Open-Core Release**: public artifact tag **`v1.0.0`**, self-host install docs, no marketing launch campaign. Tag means installable, API-frozen, lab-verified kernel — **not** battle-tested customer proof.

Per ADR `0003-v1-tag-vs-proven-claims.md`:

| Claim type | When allowed |
| --- | --- |
| Self-host install works / open-core kernel | At `v1.0.0` tag after local gates |
| Governed real partner production | After Pilot Done (Unaided) on Pilot #1 |
| Repeatable across teams | After clone Pilot #2 |

## Entry criteria

```text
- v0.7.0 engineering complete (playbooks, evidence export, security baseline)
- Local release:verify green (typecheck, build, tests, policy:regression)
- smoke:fresh-install green
- release:artifacts generatable
- No open P0/P1 in product code
- Frozen /v1 API contract documented
```

**Local status (2026-07-08):** entry criteria for code/package are met. See `actantosd/docs/go-no-go-v1.md`.

## Non-goals

```text
- Launch blog / HN / paid ads
- Requiring two living external pilots before the open-core tag
- New feature development (feature freeze except publish blockers)
- Major architecture changes
- New API endpoints
- OIDC, gVisor, Firecracker, credential broker, SCIM, multi-tenant SaaS
- Treating fixture pilot-evidence-*.md as Proven Claim Gate
```
