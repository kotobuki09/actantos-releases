# v0.6.0 — Security Beta

> **Status:** ✅ **COMPLETE** (historical). Residual hardening (seccomp/AppArmor, gVisor) stays under **Pilot Freeze** unless Escape Hatch. Do not open new tickets here by default.
>
> **Prerequisites:** Read `00_global_rules_and_teams.md` first for team lanes, global rules, and ticket format.
>
> **Canonical next work:** `v1.0.0_plan.md` then `design_partner_window_plan.md`. See ADR `0002-pilot-freeze-and-escape-hatch.md`.

## Goal
Prove fail-closed behavior under faults, harden tokens/scope checks, build audit verifier, and run red-team matrix.

## Entry criteria
```text
- v0.5.0 tagged
- Policy/budget/dry-run semantics locked
- Self-host package works
- Admin auth enabled
```

## Non-goals
```text
- SOC2 compliance certification
- Formal mathematical proofs
- Automated continuous red-teaming (future)
- Penetration testing by external firm (separate engagement)
```

## Workstreams

### v0.6-A: Fail-Closed Chaos Tests
**Owner:** A5 Security/QA
**Support:** A1 Core API/DB, A3 Pi Adapter, A4 MCP Gateway

**Faults to inject:**
```text
- actantosd down
- actantosd slow/timeout
- DB timeout
- DB connection refused
- Cedar timeout
- Cedar malformed output
- malformed decision response
- invalid JSON response
- network partition between adapter and daemon
- unsupported schema version
```

**Tasks:**
```text
v060-CHAOS-001 Build chaos test harness
v060-CHAOS-002 Add adapter daemon-down tests
v060-CHAOS-003 Add MCP gateway daemon-down tests
v060-CHAOS-004 Add DB timeout test
v060-CHAOS-005 Add Cedar timeout/malformed output test
v060-CHAOS-006 Add malformed response test
v060-CHAOS-007 Add evidence report generation
```

**Done when:**
```text
- 100% injected faults produce no execution
- Denials/failures are auditable where possible
- No adapter falls back to execute on any fault
```

### v0.6-C: Audit Verifier
**Owner:** A5 Security/QA
**Support:** A1 Core API/DB, A8 DevOps/CLI

**Tasks:**
```text
v060-AUD-001 Build audit export reader
v060-AUD-002 Recompute canonical event hash
v060-AUD-003 Verify prev_hash chain
v060-AUD-004 Detect missing event
v060-AUD-005 Detect reordered event
v060-AUD-006 Detect modified payload
v060-AUD-007 Produce verification report
v060-AUD-008 Sign verification report
v060-AUD-009 Add CLI command: actantos verify-audit --session <id>
```

**Report should include:**
```text
- session_id
- tenant_id
- event count
- first seq
- last seq
- first hash
- last hash
- verification status
- detected errors
- verifier version
- signature
```

**Done when:**
```text
- Verifier passes valid timeline
- Verifier detects simulated tampering (missing, reordered, modified events)
- Report can be attached to pilot evidence package
- CLI command produces verifiable output
```
